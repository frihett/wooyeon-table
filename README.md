# 우연한 식탁 — 참가자 웹앱 + 운영자 어드민 (해커톤 MVP)

모바일 웹브라우저용 참가자 앱(`#/home`)과 운영자 웹 어드민(`#/admin`)이 하나의 정적 웹앱에 들어 있습니다.
빌드 과정이 없어서 폴더 그대로 어디에나 배포할 수 있습니다.

## 실행 · 배포

- 로컬: 이 폴더에서 정적 서버 실행 (예: `npx serve .` 또는 `ruby -run -e httpd . -p 5173`)
- 배포: Vercel / Netlify / GitHub Pages에 이 폴더를 그대로 올리면 됩니다 (빌드 명령 없음, 출력 폴더 = 루트).
- 데이터: 해커톤 데모용으로 브라우저 `localStorage`가 백엔드 역할을 합니다. 오른쪽 위 **데모 시각 → 데모 초기화**로 언제든 처음 상태로 돌아갑니다.
- 시드 데이터: `우연한식탁_가상데이터.xlsx`의 신청자 294건 → 동일인 병합 255명 (`js/seed-data.js`). 과거 수기 운영 기록은 '이전 만남'과 피드백 데이터로 변환되어 매칭에 반영됩니다.

3. 홈/알림에서 확정 푸시 → 테이블 상세(식당·예약명·지도·구성원 제한 공개·'왜 이 테이블인가요?') → 단체방 (§18-6,7)

6. 다음 매칭: '다시는'/신고/차단 관계는 같은 테이블 금지, 이전에 만난 쌍은 감점 (§18-11) — 어드민 매칭 모니터에서 '이전 만남 N쌍'·'충돌 없음' 확인
7. 어드민 → 대시보드·예외 처리함: 식당 재고 부족 · 푸시 실패 · 환불 실패 · 노쇼 후보 · 신고만 올라옴 (§18-12)

## 직접 정한 운영 정책 (PRD 미정 항목 · FAQ 기준)

**매칭 마감 = 환불 마감** · 모임 2일 전 화요일 24:00. 이 시각에 결제 완료자만 자동 매칭.

**취소**
- 화 24:00 전: 전액 자동 환불 (계좌 입력 없음, 원결제수단)
- 수요일: 취소 가능, 환불 불가, 경고 1점 (`CANCELED_LATE`)
- 목요일 당일: **앱에서 취소 불가**. 대신 '참석이 어려워요'로 미리 알리면 노쇼(3점) 대신 2점 + 단체방 안내

**노쇼 · 제한**: 종료 시각까지 체크인 없으면 노쇼 *후보* → 운영자 확인 후 확정(3점, 이용권 차감). 누적 3점 → 4주 신청 제한(자동 해제 후 점수 초기화). 6점 이상 또는 안전 신고 → 영구 제한 검토 예외.

**확정 후 취소로 3명이 남으면 (FAQ Q6)**
1. 같은 날짜·지역 조건이 맞는 대기자(매칭 실패자 포함)를 자동 충원
2. 없으면 남은 인원을 같은 날짜의 다른 확정 테이블(희망 지역 범위 안, 필수 조건 충족)로 자동 이동
3. 그래도 안 되면 해체 → 대체 일정·보관·환불 선택 제공. 운영 사유이므로 마감 이후라도 **전액 환불**

**이용권 (FAQ Q4·Q5)**: 1회권 9,900원 · 멤버십 1/3/6개월 35,000/75,000/120,000원(기간 내 무제한). 멤버십 이용자가 매칭에 실패하면 **실패 1회당 기한 7일 연장**.

**매칭 알고리즘** (`engine.js`)
- 필수: 결제 완료 · 날짜/지역 일치 · 4~6명 · 나이 차 8살 이내 · 차단/신고/'다시는' 관계 없음 → 절대 완화하지 않음
- 절차: 지역 배정(단일 지역 우선, 다지역은 부족한 지역 보충) → 나이순 DP 분할(최대 인원 커버, 7명+ 자동 분리) → 테이블 간 교환으로 점수 개선 → 최소 점수 미달 해체 → 같은 날짜 다른 희망 지역에 자동 재배치 → 남은 인원끼리 병합 → 최종 검증 후 자동 확정 → 남은 사람은 다음 희망 날짜로 이월, 없으면 대체 일정 제안
- 점수 (가중치는 어드민에서 조정, 기본 30/25/20/15/10 · 최소 55점)
  - 연령: 100 − 최대 나이 차 × 8
  - 성비 (FAQ Q7): 균형 100 · 혼성 80 · 한 명만 다른 성별 55 · 단일 성별 35 → 허용하되 감점
  - MBTI (FAQ Q8): E/I 섞임 40% + N/S 같은 비율 35% + T/F 섞임 25%
  - 공통 관심사: 쌍별 평균 공통 관심사 2개 이상이면 100
  - 원하는 성향: '만나고 싶은 사람'을 다른 구성원의 성향이 충족하는 비율
  - 이전 만남: 같은 테이블이었던 쌍마다 감점 (서로 '또 만나요'면 감점 없음)
- 멱등성: 같은 회차는 한 번만 실행 → 중복 테이블·중복 환불·중복 단체방 없음

**지역 (FAQ Q9)**: 서울 4개 지역(홍대/합정·강남/신논현·을지로/종로·잠실)만 운영. 시드 데이터의 서울 외 지역 신청자는 제외.

**운영자 검수 (FAQ Q10)**: 없음. 조건을 통과하면 자동 확정, 예외만 운영자에게.

**개인정보**: 확정 전 다른 참가자 정보 비공개. 확정 후에도 이름(성 제외)·연령대·직업·MBTI만. 사람별 선호와 신고는 상대에게 비공개.
